# history — 传感器时序历史(决策 D4)

实体状态(传感器、指标)的时间序列记录。

## 存储策略(已拍板)

- **设备 / 实体 / 配置元数据** → 永久存 SQLite,**无老化**(`app/models`)
- **传感器时序历史** → 默认同样写 SQLite,**开启 TTL 自动删除**,
  **原始采样保留 7 天**

## 规划

- 写入:集成上报状态变更时落库(状态变更 + 周期快照)
- 清理:APScheduler 定时任务(挂到 `app/tasks`)按 TTL 删除过期采样
- 降采样聚合(天级均值等)将来作为可选项,默认不建

## 边界

- SQLite 单文件扛不住之前不引入时序数据库;若将来切换,
  仅替换本模块实现,上层接口不变。
