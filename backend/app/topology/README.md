# topology — 网络拓扑(第一类功能边界之一)

整合各集成上报的网络邻居数据,构建「网关 / 设备 / 关系」图,
不做任何网络控制。

## 数据来源

- `openwrt` 集成上报的 ARP / 邻居表 / 无线客户端
- `snmp` 集成的 FDB / 邻居表
- 其余集成的设备自描述(型号、连接方式)
- 将来可加 mDNS/UPnP 被动发现(仅发现,不扫描入侵)

## 输出

- 设备关系图(供前端 `views/topology` 渲染)
- IP ↔ MAC ↔ 设备的绑定关系(供 wakeonlan 等消费)

## 存储

图快照存 SQLite(结构待方案确认);原始邻居数据保留在时序层(7 天 TTL)。
